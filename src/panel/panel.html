Ask for something

A thin conversational front door over the same capability API an agent calls. It picks a capability, invokes it, and reports what came back — the plain-language answer and the structured result side by side. It cannot authorise an irreversible action: that lives in a request header the chatbot does not compose, so a transfer runs up to Post Transfer and then stops for a human. Every run it starts shows up in Evidence like any other.

Teach it a new flow

Describe the task the way you would to a new colleague. A model drives the real application until it is done, and the successful run is compiled into a replayable capability. Wrap anything that changes per invocation in {{braces}} — that is what becomes a typed input rather than a value baked into the recording.
